# Stable Diffusion Image Generation Project

This project uses Stable Diffusion with KerasCV to generate AI images from text prompts.

## Technologies Used

- Python
- TensorFlow
- KerasCV
- Matplotlib

## What This Project Does
- Loads the Stable Diffusion model
- Generates an AI image from a text prompt
- Saves the generated image as generated_output.png
- Displays the generated image

## Features
AI image generation from text
Stable Diffusion model
Automatic image saving
Displays generated image
Measures generation time
